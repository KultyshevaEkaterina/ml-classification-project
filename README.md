# Проект по классификации данных на Python

Учебный проект по машинному обучению: подготовка данных и сравнение алгоритмов классификации.

## Что реализовано в исходном коде

- Загрузка и первичный анализ табличных данных с помощью pandas.
- Предобработка данных и кодирование категориальных признаков.
- Разделение данных на обучающую и тестовую выборки.
- Эксперименты с алгоритмами классификации: k-ближайших соседей (kNN), наивный Байес, метод опорных векторов (SVM), дерево решений, случайный лес и логистическая регрессия.
- Использование метрик качества классификации и подбор гиперпараметров через GridSearchCV.

## Технологии

Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Plotly.

## Файлы

- `classification.py` — экспортированный из Google Colab Python-код проекта.
- `requirements.txt` — основные библиотеки для работы с кодом.

## Как запустить

Код изначально создавался для Google Colab и использует `google.colab.files` для загрузки/скачивания файлов. Он также ожидает CSV-файл `cleaned_dataset.csv`, которого нет в этом репозитории.

1. Откройте исходный блокнот в Google Colab или подготовьте локальную среду.
2. Установите зависимости из `requirements.txt`.
3. Добавьте используемый датасет `cleaned_dataset.csv` в рабочую среду.
4. Проверьте и при необходимости адаптируйте ячейки, связанные с загрузкой данных и переменными датасета, прежде чем запускать код целиком.

> Примечание: этот репозиторий публикует учебный код как пример опыта с Python и классическим машинным обучением. Он не является проектом на основе больших языковых моделей (LLM). Результаты экспериментов следует добавлять в описание только после повторного запуска и проверки.
